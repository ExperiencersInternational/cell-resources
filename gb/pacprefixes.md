# UK PAC Code Prefixes

These are PAC code prefixes for various operators. A PAC allows you to move your number to another operator.

Please note you may not be able to move to another operator using the same PAC prefix (e.g. you can't go to Vodafone Pay Monthly from VOXI, you have to go through a special process). Part of this information is informed by community contributions, such as https://www.ispreview.co.uk/talk/threads/do-mvnos-own-numbers-or-the-actual-carriers.42339/post-380591.

* GGF - giffgaff
* HTG - Three
* LCS - SMARTY
* LEB - Lebara
* ONE - EE Pay Monthly
* SPU - Spusu
* TEL - O2 Pay Monthly
* THB - Three Business?
* TSC - Tesco Mobile
* TSL - Transatel (Mozillion etc)
* VUK - Vodafone Pay Monthly, Vodafone Pay As You Go and VOXI
